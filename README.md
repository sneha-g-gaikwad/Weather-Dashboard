# Weather-Dashboard
The Weather Dashboard is an interactive Power BI report that integrates real-time weather data and Air Quality Index (AQI) indicators using the WeatherAPI. It combines multiple visuals, DAX measures, and conditional formatting to deliver insights about temperature, forecast, air quality, sunrise/sunset times, and rain chances for different cities.
